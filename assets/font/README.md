# Bitmap Font Placeholder

A monospace bitmap font will live in this directory for use by the framebuffer
text renderer. Until the renderer is implemented, this directory only contains
licensing information and TODO notes.

## License
The future font asset must be in the public domain (e.g., the `PxPlus IBM VGA`
8x16 font) or otherwise compatible with the project license. Add the font file
and license notice here when integrating the video subsystem.
